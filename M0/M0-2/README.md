## 一、如何运行

```bash
cd M0/M0-2
python3 legacy_corr.py --config config.yaml
```

- `--config` 为**必填参数**，后面跟配置文件的路径
- 结果打印到标准输出（stdout）
- 正常结束退出码为 `0`；出错时打印可读的中文错误信息，退出码为 `1`

### 运行单元测试

```bash
cd M0/M0-2
python3 -m pytest tests/ -v
```

（`-m` 不能省，它让 Python 把当前目录加入模块搜索路径，否则找不到 `legacy_corr`）

## 二、输入文件格式要求

### 配置文件（yaml）

```yaml
input_csv: "sample_data.csv"    # 数据文件路径
columns:                        # 参与计算的两列的列名
  x: "sensor_a"
  y: "sensor_b"
task:
  name: "corr_analysis"
  verbose: true
```

| 字段 | 必填 | 说明 |
| :-- | :-- | :-- |
| `input_csv` | 是 | 数据文件（csv）的路径 |

> `input_csv` 若写成相对路径，程序会先按**当前工作目录**查找，找不到时自动改按**配置文件所在目录**查找，因此在任意目录下都能正常运行。
| `columns.x` | 是 | 作为 x 的那一列的列名 |
| `columns.y` | 是 | 作为 y 的那一列的列名 |

### 数据文件（csv）

- 第一行必须是表头，列名需与 yaml 里 `columns` 指定的名字**完全一致**（区分大小写）
- 参与计算的两列必须是**纯数字**；留空会触发错误提示
- 表头以外的行数即为样本数 `n`
- 至少要有 2 行有效数据，且两列都不能是恒定值，否则相关系数无定义

## 三、输出结果的含义

```
n = 40
mean_x = 49.43782499999999
mean_y = 43.310725
r = 0.5634747254524842
```

| 输出项 | 含义 |
| :-- | :-- |
| `n` | 参与计算的数据行数 |
| `mean_x` | x 列的算术平均值 |
| `mean_y` | y 列的算术平均值 |
| `r` | 皮尔逊相关系数 |

### r 怎么解读

`r` 衡量两列数据的**线性相关程度**，取值范围恒为 **-1 ~ +1**：

- `r = 1`：完全正相关（两列同增同减，且严格成比例）
- `r = -1`：完全负相关（一列增加另一列必定减少）
- `r = 0`：没有线性关系
- 粗略参考：0.3~0.5 弱相关，0.5~0.7 中等相关，0.7 以上强相关

> 注意：`r` 只反映**线性**关系的强弱，不代表因果关系。若算出的 `r` 超出 [-1, 1]，说明计算过程有误。

## 四、异常输入的处理

| 场景 | 输出 | 退出码 |
| :-- | :-- | :-- |
| 配置文件或数据文件不存在 | 错误：找不到文件 xxx，请检查路径 | 1 |
| 列名与数据文件不匹配 | 错误：数据中不存在配置的列 'xxx'… | 1 |
| 数据为空（只有表头） | 错误：数据为空或某列取值恒定… | 1 |
| 某一列取值恒定（方差为 0） | 错误：数据为空或某列取值恒定… | 1 |
| 数据中存在非数字内容 | 错误：数据中存在无法转换为数字的内容 | 1 |

以上所有情况**均不会把 Python 栈回溯（Traceback）抛给用户**。

## 五、改造前后对照

祖传代码 `legacy_corr.py` 原始版本存在的问题及处理：

| 问题 | 处理方式 |
| :-- | :-- |
| 没有函数封装，全是全局变量 | 拆分为 `load_config` / `load_csv` / `mean` / `correlation` / `main` |
| 没有 `if __name__ == "__main__"` 保护 | 已补充，被 import 时不会自动执行 |
| 相关系数公式错误 | 分母漏了开平方，导致结果缩小 √(dx·dy) 倍，已修正并与 `numpy.corrcoef` 比对一致 |
| 没有异常处理 | 已覆盖上述五类异常，打印中文提示并以非 0 退出码结束 |
| 路径写死，无法指定配置文件 | 已支持 `--config` 命令行参数 |
| 没有任何注释和文档 | 关键步骤均已注释，本文档说明运行方式与输出含义 |
