## 一、script3.py：类的三个层次

你这段代码其实把"类"的三个层次都写全了，而且顺序是对的。

### 第一层：只有数据（先画表格）

```python
class Student:
    name = None      # 类变量，相当于先占位
    gender = None
    age = None

stu_1 = Student()        # 造一个对象
stu_1.name = "陈俊锜"     # 往对象上填值
```

你的注释"类：创建一张表格 / 创建一个对象：把表格打印出来 / 拿笔填写表格"——这个理解**完全正确**。

### 第二层：类里加函数（成员方法）

```python
class Student2:
    name = None

    def say_hi(self):              # self 就是"这个对象"
        print(f"我是{self.name}")

stu_2 = Student2()
stu_2.name = "jjj"
stu_2.say_hi()                     # 括号里不用传 self
```

`say_hi2(self, msg)` 那个写法也对：**`self` 是第一个位置，外部参数从第二个开始**。

### 第三层：`__init__` 自动执行

```python
class info:
    def __init__(self, name, age, gender):
        self.name = name
        self.age = age
        self.gender = gender
        print("看到这行时。说明init自动执行")

begin = info("人", 30, "男")        # 一造对象就自动跑 __init__
```

你的注释"看到这行时，说明 init 自动执行"——**这就是 `__init__` 的全部意义**，你抓到了。

### 三个可以改进的点

1. **`print(begin.    name)`**：点和属性之间有空格，Python 允许，但很不规范，答辩时显得随意。改成 `begin.name`。
2. **`Clock.ring()` 里用了 `winsound`**：这是 Windows 专有模块，Linux（Ubuntu）里没有。以后代码要进 WSL 跑，这种写法会直接报错。
3. **类变量 `name = None` vs `self.name`**：
   - 写在类里的 `name = None` 是**所有对象共享**的默认值
   - 写在 `__init__` 里的 `self.name = name` 才是**每个对象自己的**
   你在 `info` 类里做对了，`Student` 那两段是入门写法，能懂就行。

## 二、script4.py：继承与 super

### 单继承

```python
class Phone:
    producer = "hm"
    def call_by_4g(self): ...

class Phone2022(Phone):     # 括号里是父类
    def call_by_5g(self): ...

phone = Phone2022()
phone.call_by_4g()          # 父类的，直接能用
```

### 多继承 + 同名属性的优先级

```python
class MyPhone(Phone, RemoteControl, NFCReader):
    pass

print(phone.producer)       # Phone 和 NFCReader 都有 producer，取 Phone
```

你的注释"**优先级：先来后到**"——对的。专业说法是 **MRO（方法解析顺序）**，从左到右查。

### 复写 + super()

```python
class MyPhone(Phone):
    producer = "ITHEIMA"                  # 复写父类属性

    def call_by_5g(self):
        print(f"父类厂商是{super().producer}")   # 取父类的值
        super().call_by_5g()                     # 调父类的方法
```

`super()` 就是"我的父类"。`super().producer` 是"父类身上那个 producer"。

## 三、script5.py：多线程

```python
sing_thread = threading.Thread(target=sing, args=("唱",))
dance_thread = threading.Thread(target=dance, kwargs={"msg": "跳"})
sing_thread.start()
dance_thread.start()
```

`args` 传元组、`kwargs` 传字典。**注意 `("唱",)` 那个逗号不能省**——没有逗号 `("唱")` 就只是字符串，不是元组。

## 四、和 ROS 代码的对照（这张表最值钱）

| 你的练习 | ROS 里的对应 |
|---|---|
| `class Student:` | `class Talker(Node):` |
| `class Phone` → `class MyPhone(Phone)` | `Node` → `class Talker(Node)` |
| `super().call_by_5g()` | `super().__init__('my_talker')` |
| `begin = info(...)` 时 `__init__` 自动执行 | `node = Talker()` 时自动注册节点 |
| `self.name` | `self.pub`、`self.count` |
| `def say_hi(self)` | `def tick(self)`、`def on_target(self)` |

**你现在回头看 `talker.py`，应该能读懂了：**

```python
class TargetPublisher(Node):
    def __init__(self):
        super().__init__('target_publisher')      # ← 跟你 script4 的 super() 一样
        self.pub = self.create_publisher(...)     # ← 跟你 self.name 一样，把东西存在自己身上
```

你昨天看不懂的那两行，就是 script4 里你已经写过的 `super().call_by_5g()` 的同一个东西。

## 五、顺手发现的三个问题（其他文件，跟今天无关但值得改）

1. **`02_while求和练习.py` 第三题**：`1-2+3-4+...+99`，你的结果是 **49**，正确答案是 **50**。
   原因：循环里 `z = z + x - y` 在 x=99、y=100 时减掉了 100，最后再 `+99` 抵消不回来。改成循环只到 97，最后单独 +99。

2. **`17_异常与模块笔记.py` 的 `finally`**：`f = open(...)` 写在 `try` 里，如果 open 就失败了，`f` 根本没创建，`finally` 里的 `f.close()` 会再抛一个 `NameError`。规范写法是先 `f = None`，再在 finally 里判断。

3. **`12_数据容器笔记.py`** 里写"`my_set.pop()` 随机去掉一个元素"——准确说法是"**任意**一个"，不是随机（不保证分布）。
