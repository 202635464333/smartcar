# SmartCar

华工智能车队创意组一轮考核仓库。

## 环境

Windows 11 + WSL2 + Ubuntu 22.04 LTS + ROS2 Humble（桌面版）

## 仓库结构

```
SmartCar/
├── M0/                # 工程基础（必做）
│   ├── M0-1/          # 环境搭建 ✅
│   ├── M0-2/          # 代码重构
│   ├── M0-3/          # 代码调试
│   └── M0-4/          # 任务调度器实战
├── M1/                # ROS 系统集成（专业模块）
│   ├── M1-1 ~ M1-4/
└── README.md          # 本文件
```

## AI 使用说明

本仓库各题均使用了 AI 助手，程度不同，按题目如实声明：

| 题目 | AI 参与程度 | 说明 |
| :-- | :-- | :-- |
| M0-1 环境搭建 | 指导 | 在 AI 指导下完成，命令均由本人执行验证 |
| M0-2 代码重构 | 后半段 | 前半部分本人独立完成；异常处理及其之后的收尾（异常处理、测试、README）由 AI 完成或改写 |
| M0-3 代码调试 | 约一半 | 4 处缺陷由本人独立发现并修复；其余 6 处中约一半的修复代码由 AI 生成或改写 |
| M0-4 任务调度器 | 绝大部分 | 代码主体由 AI 生成或改写，本人负责提出需求、运行验证与结果核对 |

各题的具体分工见对应目录下的 README。
